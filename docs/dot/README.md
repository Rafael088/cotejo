# Referencia del dot

Copia literal del laboratorio de `prototipo-board/` del vault (`avatar.html`, `avatar.css`,
`tokens.css`), la referencia de verdad con la que se mide el dot del board
(`herramientas/dot_oro.py` saca de aquí el oro de `pruebas/oro/dot/`). No se edita: si el
laboratorio cambia, se vuelve a copiar y se regenera el oro.

`avatar.html` enlaza también `styles.css` y las fuentes de Google; no se copian porque solo
visten los botones y el fondo de la página, no el dot. Sin ellos el dot sale igual.
