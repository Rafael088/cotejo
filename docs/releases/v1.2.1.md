# Cotejo 1.2.1 (beta)

Una versión de arreglos sobre la 1.2: Obsidian deja de ver tareas que no son suyas dentro de los
repos de código que cuelgan de un proyecto, y el board se entera solo de lo que se escribe en
`.cotejo/` con la ventana abierta.

> [!WARNING]
> **Cotejo 1.2 sigue siendo software en fase beta.** Todavía puede tener fallos o comportarse de
> forma inesperada. Se ofrece «tal cual», sin garantías de ningún tipo, como dice su licencia
> ([`LICENSE`](https://github.com/Rafael088/cotejo/blob/main/LICENSE), cláusula 8). Haz copia de
> tu segundo cerebro antes de probarlo y, si algo falla, cuéntalo en un
> [issue](https://github.com/Rafael088/cotejo/issues).

## Descargar

Cada archivo se descarga con su enlace, o desde la lista **Assets** al final de esta página.

| Sistema | Archivo | Cómo se instala |
|---|---|---|
| Windows 10/11 (64 bits) | [`Cotejo-1.2.1-windows-x64-instalador.exe`](https://github.com/Rafael088/cotejo/releases/download/v1.2.1/Cotejo-1.2.1-windows-x64-instalador.exe) | Doble clic y siguiente. |
| Arch Linux / Omarchy | [`cotejo-1.2.1-1-any.pkg.tar.zst`](https://github.com/Rafael088/cotejo/releases/download/v1.2.1/cotejo-1.2.1-1-any.pkg.tar.zst) | `sudo pacman -U cotejo-1.2.1-1-any.pkg.tar.zst` |
| Otras distribuciones de Linux | [`cotejo-1.2.1-linux.tar.gz`](https://github.com/Rafael088/cotejo/releases/download/v1.2.1/cotejo-1.2.1-linux.tar.gz) | Ver abajo. |

**Si ya tienes la 1.0, la 1.1 o la 1.2.0**, instala la 1.2.1 encima igual que la primera vez: tus tareas viven en tu
vault o en tu repo, y el instalador no las toca. `cotejo --version` debe decir `cotejo 1.2.1`.

**Windows.** El instalador no pide administrador: instala Cotejo para tu usuario, lo pone en el
menú Inicio, añade el comando `cotejo` al PATH (para ti y para tus agentes), instala las
tipografías del board y avisa a los agentes que tengas (Claude Code, opencode…). Al terminar
abre el board. Abre una terminal nueva para usar `cotejo`; `cotejo doctor` dice qué falta
configurar. Se desinstala desde *Configuración → Aplicaciones*.

**Linux.**

```sh
tar -xzf cotejo-1.2.1-linux.tar.gz
cd cotejo-1.2.1
./install.sh
```

## Comprobar la descarga

Los SHA-256 de todos los archivos están en
[`SHA256SUMS`](https://github.com/Rafael088/cotejo/releases/download/v1.2.1/SHA256SUMS). En Linux,
con los archivos en la misma carpeta: `sha256sum -c --ignore-missing SHA256SUMS`. En Windows, en
PowerShell: `Get-FileHash Cotejo-1.2.1-windows-x64-instalador.exe`, y compara con su línea.

`Cotejo-1.2.1-fuentes-terceros.tar` trae el código fuente de los componentes LGPL/GPL que
incluye la versión de Windows, los mismos que lleva este instalador. No hace falta para usar
Cotejo.

## Arreglos

- **Obsidian ya no lee tareas de los repos anidados.** Si dentro de la carpeta de un proyecto hay
  un repo de código (una carpeta con su propio `.git`, sea clon, worktree o submódulo) o un
  `node_modules`, sus `.md` ya no aportan casillas falsas a la lista. La carpeta del proyecto se
  sigue leyendo aunque ella misma sea un repo. Lo mismo vale para las carpetas sueltas (Inbox) y
  para lo que vigila el board.
- **El board ve solo una decisión propuesta por la CLI.** Antes vigilaba `.cotejo/` pero no sus
  subcarpetas, y una decisión nueva en `.cotejo/decisiones/` (o un problema, un aprendizaje…) no
  aparecía hasta pulsar Ctrl+R. Ahora vigila también cada carpeta del almacén.
