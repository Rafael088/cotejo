## Descargar

Cada archivo se descarga con su enlace, o desde la lista **Assets** al final de esta página.

| Sistema | Archivo | Cómo se instala |
|---|---|---|
| Windows 10/11 (64 bits) | [`Cotejo-1.0.0-windows-x64-instalador.exe`](https://github.com/Rafael088/cotejo/releases/download/v1.0.0/Cotejo-1.0.0-windows-x64-instalador.exe) | Doble clic y siguiente. |
| Arch Linux / Omarchy | [`cotejo-1.0.0-1-any.pkg.tar.zst`](https://github.com/Rafael088/cotejo/releases/download/v1.0.0/cotejo-1.0.0-1-any.pkg.tar.zst) | `sudo pacman -U cotejo-1.0.0-1-any.pkg.tar.zst` |
| Otras distribuciones de Linux | [`cotejo-1.0.0-linux.tar.gz`](https://github.com/Rafael088/cotejo/releases/download/v1.0.0/cotejo-1.0.0-linux.tar.gz) | Ver abajo. |

**Windows.** El instalador no pide administrador: instala Cotejo para tu usuario, lo pone en el
menú Inicio, añade el comando `cotejo` al PATH (para ti y para tus agentes), instala las
tipografías del board y avisa a los agentes que tengas (Claude Code, opencode…). Al terminar
abre el board. Abre una terminal nueva para usar `cotejo`; `cotejo doctor` dice qué falta
configurar. Se desinstala desde *Configuración → Aplicaciones*.

**Linux.**

```sh
tar -xzf cotejo-1.0.0-linux.tar.gz
cd cotejo-1.0.0
./install.sh
```

[`SHA256SUMS`](https://github.com/Rafael088/cotejo/releases/download/v1.0.0/SHA256SUMS). En Linux,
con los archivos en la misma carpeta: `sha256sum -c --ignore-missing SHA256SUMS`. En Windows, en
PowerShell: `Get-FileHash Cotejo-1.0.0-windows-x64-instalador.exe`, y compara con su línea.

incluye la versión de Windows, los mismos que lleva este instalador. No hace falta para usar
Cotejo.

## Novedades

- **CotejoBoard**: board de GTK 4 + libadwaita con cuatro columnas (Pendiente, Haciéndola, Para comprobar, Finalizada), arrastre, atajos de teclado y selector de temas.
- **CLI para agentes**: verbos `tareas`, `tomar`, `entregar`, `bloquear`, `asignar`, `crear` y `estado`, todos en JSON.
- **Enrutador integrado**: `plan`, `decidir`, `despachar`, `revisar`, `maestro` y `protocolo` para saber qué modelo atiende cada tarea.
- **Una sola versión**: `tareas.__version__` es la única fuente de verdad para Linux, Windows y los artefactos.
- **Fuentes**: Obsidian como fuente principal; adaptador de Notion vía `cotejo-notion`.
- **Medidor de ahorro**: cuenta los tokens que la CLI ahorra frente a leer las notas enteras.
- **Windows sin código GPL en el proceso de Cotejo**: las dos bibliotecas GPL que GTK arrastraba
  sin usarlas (jbigkit y lzo2) se sustituyen por versiones vacías propias, y los programas GPL
  de otros paquetes no se instalan. Cada componente del runtime lleva su licencia en
  `runtime\share\licenses\`.
