# Cotejo 1.0 — el alcance, congelado

Decidido el 2026-09-28 (tarea `cotejo-z6s1ue`), sobre `ae87677` y las 20 tareas abiertas ese día.

## El criterio

**Lo que cambia bytes del binario entra antes de compilar; lo demás no bloquea el binario.**
Compilar Windows cuesta una tarde, 600 MB de runtime y una prueba en otra máquina. Cualquier
cambio en `tareas/`, `enrutador/`, `skills/`, `data/` o los lanzadores después de compilar es
compilar otra vez. Los scripts de instalación, la web, el dominio y los repos viven fuera del
bundle: pueden llegar después sin tocar lo compilado.

La 1.0 se lanza como **descargas en GitHub Releases** (ZIP e instalador de Windows, paquete de
Linux) con sus checksums. La instalación por comando y la web son la 1.1.

## Lo que se sabe que falta y se acepta

- **macOS** tiene rutas (`tareas/rutas.py`) pero no paquete: la 1.0 es Linux y Windows.
- **Windows sin probar en Windows**: `construir.py` no puede correr los `.exe` desde Linux.
  El board, `doctor` y los iconos SVG se comprueban por primera vez en `egenwi`.
- **Clientes `.cmd` en Windows**: un cliente de IA instalado como `.cmd` (npm) no se lanza desde
  `subprocess` sin `shell=True`. Hay que confirmarlo en `egenwi` con el `claude` que haya allí.
