# El MCP de Notion y la API de Notion son caminos distintos

El MCP de Notion y la API de Notion son caminos distintos: el MCP (cuenta de claude.ai) sirve para preparar y verificar bases; un programa propio necesita una integración interna con token y que la base se comparta con ella (… → Conexiones), o Notion contesta 404.
