# Con enrutador.proyectos configurado, Cotejo se usa a sí mismo

Con enrutador.proyectos configurado, Cotejo se usa a sí mismo: despachar crea el worktree y la rama cotejo/<id>, y entregar --prueba --repo deja evidencia que comprobar puede repetir. Los agentes necesitan el cotejo instalado al día para usar banderas nuevas.
