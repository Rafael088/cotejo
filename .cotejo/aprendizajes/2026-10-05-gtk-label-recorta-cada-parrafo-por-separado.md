# Gtk.Label recorta cada párrafo por separado

Gtk.Label recorta cada párrafo por separado: con lines=3 y saltos de línea dentro del texto, una evidencia de tres párrafos daba nueve líneas con tres «…». Para una vista previa dentro de una carta hay que aplastar los saltos a espacios y dejar el texto entero para el detalle.
