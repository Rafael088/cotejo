# Tragarse un error para que la app no se caiga convierte un fallo en una ausencia, y una…

Tragarse un error para que la app no se caiga convierte un fallo en una ausencia, y una ausencia no se investiga: nadie busca la tarea que no sabe que falta. Seguir adelante está bien; hacerlo callado, no. El arreglo no fue un sistema de logs, fue una lista de avisos que viaja con los datos hasta donde se miran.
