# Para ver las clases CSS reales de un widget de libadwaita, recorrer get_first_child() /…

Para ver las clases CSS reales de un widget de libadwaita, recorrer `get_first_child()` / `get_next_sibling()` e imprimir `get_css_classes()` es más rápido que buscar en la documentación.
