# Codex usa el mismo formato de skill que Claude Code

Codex usa el mismo formato de skill que Claude Code: una carpeta por skill con un SKILL.md de frontmatter name/description, en ~/.codex/skills/. Un protocolo escrito una vez se le puede dar nativo a los dos sin adaptarlo; a los que solo tienen un archivo de instrucciones (Gemini CLI, opencode) les toca un bloque corto que apunte a dónde pedir el resto.
