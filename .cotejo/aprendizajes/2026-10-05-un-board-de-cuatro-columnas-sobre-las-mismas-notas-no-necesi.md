# Un board de cuatro columnas sobre las mismas notas no necesita base de datos ni servidor

Un board de cuatro columnas sobre las mismas notas no necesita base de datos ni servidor: el estado cabe en la línea de la tarea, y el board es solo otra vista de lo que ya se escanea.
