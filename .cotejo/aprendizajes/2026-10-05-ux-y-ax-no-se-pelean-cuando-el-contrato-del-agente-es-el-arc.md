# UX y AX no se pelean cuando el contrato del agente es el archivo y la interfaz es solo…

UX y AX no se pelean cuando el contrato del agente es el archivo y la interfaz es solo una vista: se pudo rediseñar el board entero —lateral, agrupación, animación— sin cambiar un solo tag de los que lee o escribe el agente.
