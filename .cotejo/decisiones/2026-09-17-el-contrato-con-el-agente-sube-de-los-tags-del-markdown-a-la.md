# El contrato con el agente sube de los tags del Markdown a la CLI de Cotejo; los tags…

El contrato con el agente sube de los tags del Markdown a la CLI de Cotejo; los tags pasan a ser detalle de cómo la fuente Obsidian guarda las cosas

**Por qué:** Mientras el contrato sea el tag en la línea, solo sirve para vaults de Obsidian con 01-Proyectos y tareas - [ ]: cada segundo cerebro nuevo sería un contrato nuevo y cada agente habría que reprogramarlo. Con la CLI en medio, Logseq, Todoist o una carpeta de Markdown pelada son adaptadores

**Descartado:** Dejar que cada agente lea y escriba el Markdown directo; un MCP por cada fuente
