# Cambiar de fuente es un comando (cotejo fuentes usar X)

Cambiar de fuente es un comando (cotejo fuentes usar X): la app vigila la carpeta de la config y reabre la fuente sola; si la nueva no abre, se queda la anterior

**Por qué:** Antes había que reiniciar el proceso de fondo y nadie lo recuerda; así el board y la barra cambian al instante y un agente lo hace en una llamada

**Descartado:** Reiniciar el proceso a mano; que la skill reinicie el proceso
