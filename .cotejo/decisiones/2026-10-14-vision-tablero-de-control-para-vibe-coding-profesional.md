# Visión: tablero de control para vibe coding profesional

Cotejo es el tablero de control para hacer vibe coding profesional. Los agentes escriben el código; Cotejo organiza el proyecto (contexto, decisiones, arquitectura y versión en .cotejo/ dentro del repo), manda cada tarea al modelo adecuado y no da nada por hecho sin evidencia y sin la revisión de una persona. Se usa con cualquier agente de terminal o cliente MCP; gratis en Windows y Linux (licencia propietaria, no libre).

Los desarrolladores siguen primero; quien no programa entra a través de su agente y de una revisión en lenguaje llano (el resumen de cada entrega), sin una interfaz propia.

**Por qué:** la versión 1.2.4 abre la beta pública y la promesa nueva habla de los dos públicos; la barrera de quien no programa no es instalar ni crear el proyecto (lo hace su agente) sino comprobar lo entregado.

**Descartado:** una interfaz o asistente gráfico propio para no programadores (la gente acude primero a un agente); presentarse como «app que escribe el código»; prometer productividad («10x»); y lo que ya descartaba dec-4dmg (carpeta central, sincronizar de ida y vuelta con Obsidian, notas libres sin estructura).
