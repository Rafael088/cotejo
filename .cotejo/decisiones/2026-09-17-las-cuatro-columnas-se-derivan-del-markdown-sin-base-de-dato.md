# Las cuatro columnas se derivan del Markdown, sin base de datos

Las cuatro columnas se derivan del Markdown, sin base de datos: Pendiente es un [ ] sin tag, Haciéndola es #en-curso, En espera es #por-validar y Finalizada es [x]

**Por qué:** El estado cabe entero en la línea de la tarea, así que el vault sigue siendo la única fuente y todo se ve igual desde Obsidian. Una base de datos aparte obligaría a sincronizar dos verdades

**Descartado:** Archivo de estado aparte con el mapa de tareas
